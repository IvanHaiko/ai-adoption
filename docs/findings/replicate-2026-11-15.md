Повторён прежний дизайн: по три страницы по 25 моделей в сортировках
newest-created, oldest-created и latest-version, затем отдельная коллекция
language-models. Только чтение публичных метаданных; predictions не запускались.
Ключ использован лишь в окружении процесса и не сохранялся в результатах.

Это смещённая проба нескольких областей активности и модальностей, не случайная
выборка. Коллекция тоже содержит закрытые и нерелевантные текущему text-generation
проекту модели. Поэтому процент совпадения нельзя интерпретировать как покрытие
всего Replicate или доступность модели во всём интернете.

Совпадение единственной модели основной пробы — openai/gpt-oss-120b.
Коллекция дополнительно даёт deepseek-ai/DeepSeek-V3-0324,
ibm-granite/granite-3.3-8b-instruct и
Qwen/Qwen3-235B-A22B-Instruct-2507-FP8. Это ровно **четыре разных HF repo**
в объединении двух наборов. Ссылка Qwen указывает на FP8-репозиторий: обычные
веса и другие точности не объединялись. Поле weights_url — явная декларация
платформы о весах, а не независимая проверка реально запущенной версии.

## Сравнение с первым октября

В двух основных пробах есть 110 общих точных Replicate ID с run_count.
Среди этих 110 между наблюдениями ни одного уменьшения счётчика не выявлено.
Для openai/gpt-oss-120b: 512 321 → 598 052, разница **85 731 запуска**.
Два разнесённых наблюдения не дают дневной серии, числа пользователей,
производственного использования и гарантии отсутствия промежуточных сбросов.
Менявшиеся версии модели под одним Replicate ID также не доказаны одинаковыми.

Практическая ценность — дополнительный накопительный сигнал запусков у небольшой
подтверждённой группы моделей. Для массового обнаружения новых текстовых моделей
источник пока слаб: широкий проход принёс одно совпадение, а дешёвая коллекция
— четыре. Стоит регулярно читать фиксированные четыре точных Replicate ID плюс
коллекцию для новых явных ссылок, сохраняя ID версии и изменения ссылок. Полный
ежедневный обход каталога сейчас не оправдан. Сам график run_count можно строить
только после повторных наблюдений с проверкой отрицательных изменений.
