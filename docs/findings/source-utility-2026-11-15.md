# Полезность новых источников: реальный сбор 15.11.2026

Пилот OpenRouter и Cloudflare запрошен за 30 завершённых UTC-дней
16.10–14.11.2026, тот же интервал, что у сохранённого Vercel. Replicate —
ограниченная проба текущего каталога и сравнение с пробой 01.10.
Выполнялись только GET статистики/метаданных, без запусков моделей.

## OpenRouter — подключать первым

Получены **1 530 строк**: 50 именованных моделей и Other за каждый из 30 дней,
всего **79 различных model_permaslug**. Пропущенных дней нет.
Объём — 809 597 615 314 341 исходный токен по методике источника.
Топ-50 содержит **94,9382%** этого объёма, Other — **5,0618%**.

На HF ссылается 31 различный permaslug, в сумме 32 HF ID. Один маршрут Nvidia
в разные даты ссылается на два репозитория; это сохранённая смена декларации,
а не основание объединить ID. Из 32 HF repo 29 уже наблюдались в Gold, лишь
три относятся к его основной когорте. Наличие HF-ссылки не доказывает лицензию
открытых весов. Остаток без HF-ссылки также не является автоматически закрытым.

Первые два permaslug по сумме токенов — разные версии DeepSeek V4.1 Flash;
их нельзя незаметно объединять при анализе релизов. Модель вне ежедневного
топ-50 имеет неизвестный объём, не ноль. Каталог снят в один момент суток,
поэтому атрибуция здесь **по декларации того же календарного дня**, а не
доказанная идентичность каждого запроса в течение суток.

Особенно полезен контраст с Vercel: у Beam 1.0 там 20,539% текстовых токенов
12.11 и 24,3396% 14.11; в OpenRouter Rankings Daily за весь пилот Beam не
попал в именованный топ-50. Установлено различие наблюдаемой видимости на
шлюзах, а не отсутствие OpenRouter-трафика. Один шлюз не представляет рынок.

## Cloudflare — отдельный ряд инференсов

Доступ к Radar подтверждён; сохранены summary и дневные распределения по
моделям и задачам. В сводке за период **87,0770%** инференсов — Text Embeddings,
**7,5896%** — Text Generation. Одна bge-m3 даёт **83,9396%** общего объёма.
Таким образом, широкий рейтинг Workers AI отражает существенно другой состав
задач, чем текстовые шлюзы. До сопоставления языковых моделей нужно установить
явные model/task и HF-связи; удаление префикса @cf само по себе этого не доказывает.

Это доли инференсов, а не токены или число компаний. Сырые распределения
нельзя складывать с OpenRouter. Данные и лицензия CC BY-NC 4.0 хранятся
отдельно от CC BY 4.0 выгрузок шлюзов.

В расширенном ответе 90 именованных моделей и 30 полных дней: 2 700 строк
модель/день и 300 строк задача/день. API вернул лишнюю точку на границе
15.11; она исключена. Суммы дневных распределений проверены около 100%.
Подробный разбор: [Cloudflare](cloudflare-2026-11-15.md).

## Replicate — небольшой фиксированный набор

10 GET-запросов дали 225 строк / 221 уникальную модель широкой пробы;
отдельная language-models collection — 39 моделей. Все страницы широкой пробы
имели следующий курсор; размер полного каталога неизвестен.

В широкой пробе 16 явных HF-ссылок, но только одна на repo из текущего Silver.
В небольшой коллекции — пять HF-ссылок, четыре точных совпадения с Silver;
объединение обеих выборок — **четыре HF repo**. Дешёвая коллекция полезнее
широкого сканирования для текущего охвата проекта.

У всех 221 модели есть run_count. С 01.10 совпали 110 Replicate ID;
уменьшений счётчика между двумя датами нет. Для gpt-oss-120b он вырос
с 512 321 до 598 052: **85 731 запуска между наблюдениями**. Это не дневная
серия и не уникальные пользователи. Из двух дат нельзя доказать отсутствие
промежуточных сбросов или стабильность будущей методики.

Рекомендация — фиксированный набор с явными ссылками плюс проверка коллекции
на новые точные связи. Полный ежедневный каталог пока не оправдан.
[Детальный отчёт](replicate-2026-11-15.md); данные —
data/spikes/replicate/2026-11-15 (4 763 194 байта gzip, хеши проверены).

## Решение

1. OpenRouter + Vercel — основа витрины фактического использования на шлюзах.
   Показывать числитель, знаменатель, Other и долю атрибутируемого объёма.
2. Cloudflare — отдельная витрина структуры задач и относительного использования
   Workers AI; включать в сравнение LLM после подтверждения точных связей.
3. Replicate — целевое наблюдение накопительных запусков выбранных моделей,
   без широкого ежедневного обхода и без достраивания истории из двух точек.

Следующий прирост ценности даёт проверка идентичности высокообъёмных моделей
без HF-ссылок и регулярность измерений; увеличение числа каталогов само по себе
не улучшает ответ на вопрос об использовании. Новые workflow не публиковались.
