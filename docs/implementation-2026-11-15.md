# Доработки к обсуждению 16 ноября

Реализованы исправления Temporal/Gold, витрины наблюдаемости и хостинга,
архивирование внешних ревизий, нормализация использования на шлюзах,
контроль знаменателей и атрибуции, карточки API-моделей и список новых провайдеров.

## Проверенные результаты

- Silver и Gold пересобраны по 79 дням до 14.11.2026; в обоих ноль DQ-ошибок.
  Gold logic version 2: 51 119 репозиториев, основная когорта 43 338.
- Temporal indexer version 3 исправляет 26 160 → 1 381 для фиксированной
  когорты 14.11. Новый индекс и deployment replay сохранены отдельно;
  deployment replay содержит 331 217 наблюдений и 7 179 размещений.
  Identity replay обновлён: 309 606 кандидатов, 309 240 разрешённых связей,
  183 неоднозначных решения. Канонические семейства автоматически не назначаются.
- Полный replay событий до 14.11 завершён: 16 426 событий, включая 7 179
  первых наблюдаемых листингов, 1 077 изменений цены и 66 пересмотров HF-связи.
  Старые октябрьские артефакты сохранены; новые имеют суффикс 2026-11-15.
- Четыре витрины: 632 строки качества источников, 90 строк покрытия панели,
  1 627 записей на проверку несовпадения ID за все даты, 289 584 repo-day
  наблюдения хостинга. Очередь содержит наблюдения, не уникальные инциденты.
- Публичный 30-дневный пилот Vercel 16.10–14.11: 963 строки, все дни и три
  метрики присутствуют. Исходные байты и лицензия сохранены в data/external.
- Отдельно получены публичные справочник провайдеров и endpoints Beam.
  На 15.11 каталог перечисляет Nebius, CoreWeave, DigitalOcean, BaseTen и Together.
  Общий трафик Beam этим хостам не приписывается.
- Созданы 185 карточек с точной ссылкой OpenRouter → HF, из них 179 вне
  основной когорты. Beam связан с Vercel через отдельный проверенный ledger;
  остальные совпадения имён автоматически не принимаются. Это ретроспективное
  соответствие с recorded_at, а не доступный на дату релиза прогнозный признак.

## Запуск

```powershell
./scripts/rebuild_analytics.ps1
# Повторить публичную выгрузку за последние 30 завершённых UTC-дней:
./scripts/rebuild_analytics.ps1 -FetchVercel
# После настройки ключа в окружении:
python -m gateway fetch --source openrouter --start 2026-10-16 --end 2026-11-14
python -m gateway build --ledger data/gateway_identity_links.json
```

Команды не публикуют изменения в Git. Новый код не подключён к существующему
публикующему CI: локальный запуск и проверка доступны до вашего push.

## Границы готовности

Полный финальный набор: **230 тестов прошли**, Ruff без замечаний. В ходе
независимого ревью исправлены порядок ревизий A→B→A, неполные архивы,
отсутствующий Other и связь OpenRouter по устойчивому идентификатору.

После получения ключей 30-дневная история OpenRouter получена; Cloudflare
и Replicate проверены ограниченными реальными выгрузками. Результаты:
[полезность источников](findings/source-utility-2026-11-15.md).
Cloudflare требует учёта отдельной некоммерческой лицензии.
Akamai/Blaze включены в watchlist; их закрытые beta-каталоги и объёмы
не выдумываются. Сторонние HF архивы требуют проверки охвата до включения в метрики.
Семейства моделей не объединены: соответствие квантований и базовых весов
остаётся отдельной исследовательской задачей с явными доказательствами.

Полный Temporal replay уже существенно тяжелее Gold: JSON deployment bundle
занимает около 901 MiB, identity bundle — 1 205 MiB. Они сохраняются локально
в gitignored каталоге. Следующее инженерное улучшение этого слоя — компактные
табличные факты и потоковое чтение; его не стоит пересобирать после каждого
ручного запроса. Обычный rebuild_analytics.ps1 этот дорогой replay не запускает.
